# Questline v0.6.0 — 공부·현실 퀘스트·광산이 연결되는 RPG

## 실행

GitHub Pages: `https://tos-dori.github.io/quest/` (저장소의 Pages 설정/배포 성공 필요)

정적 웹앱이며 별도 설치나 번들러가 필요하지 않습니다. 아래 파일을 같은 디렉터리에 둡니다.

- `index.html`: 게임 UI, 기존 퀘스트·생활기록·시설·장비·탐험, 신규 학습/광산 UI
- `research-data.js`: 기존 30개 연구 개념의 원본
- `learning-expansion.js`: **강의 원본에서 선별한 새 14개 연구 개념**
- `learning-deep.js`: 기존 13개 개념의 상세 해설
- `learning-chapters.js`: **기존 간략 개념 17개 + 신규 14개** 상세 개념 강의
- `learning-cases.js`: **44개 개념에 각 2문제씩** 적용·추론 연습과 모범답안
- `research-game.js`: 연구 지도, 설명→기초→적용 2회→전이, 복습·해금·보상
- `forge-game.js`: 6종 제작·강화 장비, 2칸 장착, 학습 기술 보너스
- `mine-core.js`: 광석별 파괴 보상, 수동·자동 채굴, 집중 에너지, 장비 적용
- `cloud-config.js`, `cloud-sync.js`, `supabase.sql`: 향후 클라우드 저장을 위한 기존 준비 파일 (현재 설정 미완료)

## 게임의 핵심 흐름

1. 마을에서 **직접 채굴 또는 자동 채굴**을 하며 골드·석재·수정 수집.
2. 발전→공방에서 성장 효과가 서로 다른 장비를 제작·강화하고, **최대 2개를 선택해 장착**.
3. 연구에서 개념을 배우면 8종 기술에 대응하는 채굴 효율·보상 향상이나 공방 조기 해금이 가능.
4. 현실 퀘스트를 완료하면 최대 하루 3회 **집중 에너지**를 얻어 갱도에서 직접 소비. 별도의 일반 보상도 유지.
5. 장기적으로 채굴·자동 생산·탐험·시설·연구에 자원을 분배.

탐험대의 시간제 파견은 보조 콘텐츠로 남아 있고, 직접 채굴 및 제작 공방이 메인 성장 루프입니다. 현실 행동이나 연구를 하지 않아도 기본 게임 플레이는 계속할 수 있습니다.

## 공부의 범위와 동작

- 운영체제 12개 / 마이크로프로세서 10개 / 머신러닝 11개 / 시스템반도체설계 11개 = **44개 개념**.
- **44개 상세 강의**: 왜 필요한지(문제 상황) → 배경·개념 원리 → 원어/용어 → 도식 → 단계별 풀이·주의할 점 → 문제.
- 개념별 **4개 연습**: 기초 확인 1개, 설명형·계산형 적용 사례 2개, 전이·자기설명 1개 = **총 176개 문제**.
- 해설·힌트(골드 소비, 잔액 부족 시 무료)·모범답안 확인, 선택 및 간격 복습, 연구 테크트리 유지.
- 설명형 연습은 AI 자동 채점이 아니라 자신의 답과 모범답안을 비교하는 **자기평가**입니다.
- 강의 원본 파일명과 PDF 페이지를 연구 노드에 제공하며, 사용자가 업로드한 네 강의 자료 ZIP에서 내용을 선별했습니다. 전체 강의 범위를 완전하게 대신하는 교재는 아닙니다.

## 데이터 계약·안전

- 기존 `firstlight_rpg_v2` localStorage 저장 키, JSON `v:2`, 연구 기록 `researchV4`, 기존 재화·퀘스트·탐험 등 유지.
- 신규 `forge` 및 확장 `mine` 필드를 **기존 데이터에 추가**합니다. 데이터 강제 초기화 없음.
- 백업과 복원은 게임 상단 기록(📔) 기능을 사용합니다.
- **Supabase 연결이 아직 없으므로 기기 간 자동 동기화는 미구현**입니다. Todo Mate도 여전히 수동 가져온 사본입니다.
- 기존 게임 데이터가 중요하면 패치 전 상단 기록에서 먼저 백업하세요. 다른 GitHub Pages 주소·브라우저 프로필로 이동하면 로컬 저장 데이터는 자동 이전되지 않습니다.

## 실제 검증 범위

- 320/390/1440px Chromium에서 레이아웃·가로 넘침·런타임 오류 검수.
- 수동 채굴 4연속 터치, 장비 제작·장착, 타격 효과, 현실 퀘스트→집중 폭발, 연구 4단계→완료·저장 후 복원, 연구의 채굴 효과·기존 데이터 보존 테스트.
- 개념 노드 44개 / 상세 설명 44개 / 적용 사례 88개 / 선행관계 순환 없음, 수록한 원본 PDF 파일 존재 확인.

## 개발 방향

일관성 없는 기능·숫자 증가보다 **재화를 쓰면 플레이 경험이 바뀌고, 학습과 현실 행동이 자연스럽게 의미를 갖는 세계**를 우선합니다. 장기적으로는 더 깊은 장비 상호작용, 게임 상태의 시각화, 분야 간 통합 학습 예제를 지속 검증해야 합니다.
