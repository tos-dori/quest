# Questline v0.9.1 — 컴팩트 UI 미니 패치

v0.9.0의 저장 데이터와 게임·학습 기능은 그대로 두고 메인 화면의 불필요한 높이와 여백을 줄였습니다.

## 변경

- 마을 게임 장면의 과도한 고정 높이와 데스크톱 가로 확장을 억제: 실제 조작 영역은 중앙 최대 980px
- 모바일 현실 퀘스트·광석·채굴 강화·생산시설을 필요한 크기로 재배치
- 생산 수령·상점 아이템 격자·퀘스트 행·탐험 지역의 최소 높이와 간격 조정
- 펼친 강화 메뉴와 짧은 화면에서는 하단 고정 내비게이션에 조작이 가려지지 않도록 스크롤 여유 보존
- **학습 본문의 내용이나 게임 수치·기능은 축소/변경하지 않음**

## 측정 (로컬 Chromium)

| 화면 | v0.9.0 | v0.9.1 |
|---|---:|---:|
| 390×844 마을 문서 높이 | 895px | 844px |
| 320×700 마을 문서 높이 | 870px | 700px |
| 1440×900 마을 게임 콘텐츠 높이 | 673px | 490px |

실제 콘텐츠가 많은 연구·탐험·장비 상세에서는 필요한 스크롤을 유지합니다. 320×568처럼 높이가 작은 휴대폰과 펼쳐진 강화 메뉴에서는 하단 버튼 접근을 위해 스크롤이 생길 수 있습니다.

## 데이터 · 테스트

- 저장 키 `firstlight_rpg_v2`, JSON `v:2` 변경 없음
- 기존 로컬 게임 기록 보존, Supabase 클라우드 미활성화
- Chromium 320×700, 390×844, 1440×900: 채굴 타격, 강화 펼치기, 생산 수령, 신규 튜토리얼, 레이아웃 및 가로 넘침 검사
- 실제 iPhone Safari와 GitHub Pages 공개 주소 접속은 아직 확인되지 않음
