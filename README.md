# Questline — 현실 행동 RPG

**현재 버전: v0.3.0** · 개발/테스트용

Questline은 현실의 작은 행동과 전공 복습을 게임 성장, 탐험, 생산시설, 장비 강화로 연결하는 1인용 RPG입니다.

## 실행과 저장

게임: `index.html` · 배포 위치: `https://tos-dori.github.io/quest/` (GitHub Pages 활성화 필요).

**현재 `cloud-config.js`의 Supabase URL/키는 비어 있습니다.** 따라서 서버 동기화가 활성화된 상태가 아니며, 게임은 같은 주소·브라우저의 로컬 저장소 `firstlight_rpg_v2`에 데이터를 저장합니다. 다른 기기에서 이어하려면 게임 상단 기록(📔) → 저장·백업·복원에서 파일을 내보내고 복원하세요. 기존 저장 키와 JSON 스키마 v2는 유지합니다. `supabase.sql`과 `cloud-sync.js`는 향후 클라우드 전환을 위한 준비 코드이며, 실제 서버 연결·인증·양 기기 동작은 별도 확인이 필요합니다.

## 화면과 콘텐츠

- **마을**: 추천 현실 퀘스트, 수령 가능한 생산·탐험 보상, 생활 기록 빠른 진입
- **퀘스트**: 작은 착수 단계, 집중 시간, Todo Mate 목록 사본과 직접 추가한 할 일
- **연구**: 강의자료 기반 28개 문제, 정답 해설·출처, 신규/복습 구분, 1·3·7·14·30일 복습 주기, 전체 문제 직접 선택
- **탐험**: 10개 지역, 30개 수집 유물, 불씨를 소비하는 2·8분 탐험
- **발전**: 시설 5종(각 최대 10단계), 장비 5종(각 최대 8단계), 개척 연대기 30개 목표, 외형 꾸미기

장비와 시설은 비용 및 효과를 사전에 볼 수 있습니다. 성장과 해금은 실제 행동과 학습에서 획득한 보상에 연결되지만, **30개 연대기 목표가 30일의 플레이를 보장한다는 뜻은 아닙니다.** 일간 의무·놓친 날의 벌칙 없이 실제 사용으로 경제 밸런스를 검증합니다.

## Todo Mate

현재는 Todo Mate의 실시간 API 연결이 아닙니다. 기록(📔)에서 항목 ID가 포함된 JSON 사본을 가져올 수 있고, 게임 안에서 완료해도 Todo Mate 원본에는 반영되지 않습니다.

## Supabase 서버 저장 (후속 설정)

1. Supabase 프로젝트 생성 후 `supabase.sql` 적용 및 RLS 검증
2. Email 인증과 GitHub Pages URL의 Auth Redirect 설정
3. `cloud-config.js`에 **공개용** 프로젝트 URL과 publishable 키만 입력 (secret / service_role 키 금지)
4. 기기 간 저장·충돌·백업 복구 실제 테스트

서버 연결 전에는 계정 간 공유 저장으로 간주하지 않습니다. 사용자가 ChatGPT에 수치 수정을 명시적으로 요청할 경우, 서버 연결 완료 후 정확한 사용자 데이터와 리비전을 조회해 수정하고 변경 전 상태를 보관해야 합니다.
