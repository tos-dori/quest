# Questline v0.9.0 — 게임형 UI 재설계

기존 v0.8 게임 시스템/저장을 보존하면서 메인 정보 구조를 '설명형 웹사이트'에서 '게임 HUD·장면·선택 패널'로 변경했습니다.

## 변경

- 마을: 현재 퀘스트 → 직접 채굴 장면 → 시설의 짧은 그림 목록. 재화는 상단 HUD에 통합. 반복되는 퀘스트/연구/공방 바로가기 카드를 제거하고 하단 내비게이션을 단일 진입점으로 사용.
- 초보자: 큰 설명 카드 대신 다음 행동만 표시하는 단계형 안내를 기존 튜토리얼 시스템과 연결.
- 생산 마을: 시설별 설명 카드 다섯 개 대신 SVG 시설 그림을 고르면 오른쪽/아래 선택 패널에서 생산량·비용·업그레이드·전문화를 조작.
- 공방: 2개 장착 칸, 장비 10개 그림 격자, 한 개 선택 아이템 상세 정보/제작/장착.
- 퀘스트: 짧은 행동별 행 목록. 실제 할 일은 동작 버튼만 바로 표시.
- 탐험: 지역 선택 지도와 선택한 지역의 비용·진행 상태를 별도 패널로 분리.
- 연구: 강의 내용 44개 노드와 문제/모범답안을 보존. 지도 진입의 불필요한 소개·잡다한 상태 설명만 축소.
- Mac 데스크톱: 가로 폭을 활용한 채굴/마을, 공방/상세, 탐험/선택 패널 2열 배치.

## 저장 및 기능 계약

- `firstlight_rpg_v2` 키와 `v:2` JSON 스키마 변경 없음. 새 필드·migration 불필요.
- 기존 진행 저장이 있는 사용자는 신규 튜토리얼 잠금을 소급 적용하지 않음.
- 광산·설비·전문화·제작·학습·진행·백업/초기화 코드와 기존 게임 계산 규칙 유지.
- Supabase URL/키는 빈 값으로 유지, 서버 동기화는 미활성화. Todo Mate는 여전히 수동 가져오기 사본임.

## 코드

- `game-world-v09.js`: 게임 우선 화면 구조 렌더러(저장/게임 규칙은 건드리지 않음)
- `game-world-v09.css`: 전체 HUD/게임 세계/공방/생산 마을/탐험 UI
- `index.html`: 위 렌더러로 화면 연결, 기존 게임 기능은 유지
- `town-ui.js`, `forge-game.js`: 새 선택형 시설/장비 화면
- `mine-core.js`: 채굴 상태 표시 문구만 소폭 정리

## 검증

로컬 Chromium에서 신규 게임 및 v0.8 저장 데이터, 320/390/1440px 화면, 5개 탭, 시설 선택/강화, 공방 아이템 선택/제작, 설정 진입, 화면 가로 넘침, JS 구문/런타임 오류를 확인함.
