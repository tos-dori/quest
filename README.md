# Questline v0.9.2 — 메인 화면 구조 미니패치

Mac 화면(1733×864, 첫 모험 5/5, 갱도 13층)에서 튜토리얼 중복 안내와 채굴 과대 확장을 수정했습니다.

- 게임 HUD: 데스크톱 제목·재화·설정을 한 행으로 통합. 모바일은 헤더 내 두 행.
- 튜토리얼: 현재 목표와 실행 버튼 하나만 표시. 연구 단계에서는 퀘스트 시작 안내 중복 제거.
- 채굴: 초기 게임에서 채굴 장면의 가로 폭·높이를 콘텐츠에 맞춰 제한. 타격·강화·집중 에너지 기능 보존.
- 데스크톱 메뉴: 가운데 정렬된 짧은 게임 탭으로 조정.
- 기존 플레이어의 게임 홈, 학습 내용과 저장 데이터, 연구·퀘스트·강화 기능은 유지.

저장 키 `firstlight_rpg_v2`와 JSON `v:2` 변경 없음.

로컬 Chromium에서 1733×864·1440×900·390×844·320×700, 튜토리얼 0/3/4단계 및 기존 저장, 연구·퀘스트 진입, 광석 타격, 가로 넘침 검증. 실제 Pages 배포·iPhone 실기기 검증은 별도.
