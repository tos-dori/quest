# Questline v0.5.0 — 현실 행동 RPG · 채굴 메인 게임 · 연구 읽기 모드

## 플레이 흐름

마을: 현실 퀘스트 시작 → **끝없는 갱도**에서 자동 채굴 / 직접 타격 → 골드·석재 축적 → 곡괭이·굴착기·선별기 강화 → 더 깊은 갱도 → 5층 단위 전문 특성 선택. 생산시설·장비·탐험·꾸미기·개척 연대기는 그대로 유지함.

- 자동 채굴은 게임을 열어두지 않아도 경과한 시간에 따라 진행되며, 한 번 계산할 때 최대 8시간분을 반영.
- 직접 광석을 눌러 타격할 수 있음. 재료/골드를 투자해 세 업그레이드를 각각 최대 60레벨까지 성장.
- 5층마다(5층을 클리어해 6층에 도달하면 최초) 전문 특성 1점을 얻어 직접 타격 +28%, 자동 채굴 +15%, 보상 +12% 중 선택.
- 현실 퀘스트를 실제로 기록하면 자동 채굴 속도 3분간 1.5배. 하루 최대 3회 보너스까지.
- 기존 탐험대는 기다렸다 수령하는 **서브 콘텐츠**로 유지.

## 강의 학습

- **연구 지도 → 과목별 테크트리 → 한 개념에 집중하는 읽기 화면 → 핵심 확인 → 적용/서술 → 해설/자기평가 → 해금/복습**
- 기존 4과목 **30개 개념 노드**와 선행관계, 60개 개념/응용 문제 및 기존 복습·보상 기록을 유지.
- 그중 핵심 **13개 노드**는 실제 강의 PDF를 확인해 배경 문제, 용어 원문, 단계별 설명, 구체적 풀이를 확장. **나머지 17개 노드는 v0.4의 짧은 설명**으로 유지. 전 과목 전체를 깊이 설명했다고 주장하지 않음.
- 서술 문제는 자동 채점이 아니라 자기 답변과 모범답안 비교. 간격 복습·랜덤 재학습·힌트(골드 3 또는 부족 시 무료) 유지.
- 읽는 동안 고정 게임 하단 탭을 숨기고 '← 연구 지도'로 복귀. 지도와 정보를 동시에 강요하지 않음.
