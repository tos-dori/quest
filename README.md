# Questline v0.7.0 — 살아 있는 마을과 개념 연결 연구

현실 행동과 전공 학습, 채굴·성장·생산시설을 서로 연결한 웹 게임입니다. 현재는 **개인 개발·테스트용**입니다.

## 접속과 저장

- GitHub Pages: https://tos-dori.github.io/quest/ (Pages 배포 활성화 필요)
- 게임 데이터는 기존 `localStorage['firstlight_rpg_v2']`에 저장하고 JSON `v:2` 구조를 유지합니다.
- v0.6 및 이전 진행 상태, 재화, 퀘스트, 탐험, 학습 이력, 제작 장비를 보존합니다.
- v0.7에서 새로 생긴 `townModules`, `researchV4.missions`, `researchV4.missionReviewLog`는 기존 저장에 새 필드로 추가됩니다.
- Supabase 스크립트는 유지하지만 `cloud-config.js`의 URL·공개 키가 비어 있어 현재 **기기 간 서버 동기화는 비활성화**된 상태입니다. 맥/폰은 서로 독립 저장되며, 기록 메뉴의 JSON 내보내기/가져오기를 사용할 수 있습니다.

## v0.7의 핵심 변화

### 시설과 왕국 발전
- **생산 마을**: 제재소·채석장·연구탑·교역소·탐사 전초기지를 각각 원본 SVG 일러스트로 표시. 마을에서도 시설을 보고 누르면 관리 화면으로 이동합니다.
- 시설 생산량·해금 여부·다음 업그레이드 비용과 효과·수령 가능한 재화를 같은 시각 체계로 표시.
- 시설별 **3단계 전문화** 추가: 목재·석재·잉크·교역 골드 생산량 +20%/단계, 탐험 기본 재료 보상 +6%/단계. 각 Lv.2부터 전문화 가능. 수치 계산은 실제 생산 및 보상에 반영됩니다.
- 표시용 재화 아이콘/구매 가능 여부, 클릭 가능한 요소와 일반 정보를 구별하는 디자인을 통일. 모바일은 컴팩트한 화면, Mac은 가로 영역을 사용하며 하단 고정 메뉴를 넓은 화면에서는 상단 내비게이션으로 표시합니다.

### 제작과 채굴
- 제작 장비 **6종→10종**. 기존 장비 6종은 유지합니다.
- 추가 장비: 목재 회수 날(광석 6개마다 목재), 지식 추출기(10개마다 잉크), 수정 공명추(12개마다 수정), 전동 채굴심(직접·자동 채굴 동시 강화).
- 기존처럼 장비 장착은 **최대 2개**이며, 조합에 따라 생산 전략이 달라집니다. 신규 장비의 추가 자원은 갱도 보상과 저장 데이터에 반영됩니다.
- 채굴 장면의 지층별 색채와 시설 간 연결을 개선했습니다. 기존 탐험대와 생산시설은 별도 서브 콘텐츠로 유지됩니다.

### 연구와 학습
- 기존 **4과목 44개 개념**, 각 개념의 설명·예제·4단계 문제·간격 복습은 유지.
- 새로운 **16개 연결 문제집**: 4과목별 4개. 실제 강의 주제들을 2개 이상 조합하는 상황 문제, 단계별 풀이, 모범답안, 힌트를 수록했습니다. 선행 개념을 완료해야 열리며, 문제를 다시 풀어 소량의 재화를 받을 수 있습니다.
- 캐시·TLB·스레드·DMA·NAND/FTL·결정트리·정밀도/재현율·파이프라이닝 등에는 **주제별 자체 SVG 도식**을 추가했습니다. 다른 노드에는 설명에 맞춘 구조도/흐름도를 사용합니다. 작은 화면에서는 길고 작은 SVG 대신 읽기 좋은 수직 단계를 표시합니다.
- 읽기 화면에서는 게임 상단 재화/상태를 숨겨 학습 내용에 집중하고, 연결 문제를 아직 풀 수 없다면 첫 연구로 안내합니다.

## 콘텐츠 범위와 한계

- 44개 연구 각각 4문제, 연결 문제 16개 = **총 192개의 문제 활동**. 서술형 일부는 자동 정답 판정이 아니라 **모범답안과 직접 비교하는 자기 평가**입니다.
- 실제 학습 효과 및 수 주간 경제 밸런스는 아직 실사용 검증 전입니다. 문제·도식은 학습 보조용이며 모든 강의 내용을 빠짐없이 포괄한 교과서가 아닙니다.
- Todo Mate는 실시간 양방향 동기화가 아니라 수동으로 가져온 목록의 사본입니다.

## 코드 구성

- `index.html`: 게임 본체·UI·저장 계약
- `town-ui.css`, `town-ui.js`: 생산시설 시각화와 전문화
- `learning-visuals.js`: 개념 도식/모바일 대체 그림
- `learning-missions.js`: 16개 개념 연결 문제 콘텐츠
- `research-data.js`, `learning-deep.js`, `learning-expansion.js`, `learning-chapters.js`, `learning-cases.js`: 기존 44개 연구 콘텐츠
- `research-game.js`: 테크트리·읽기·문제·복습·연결 문제집
- `mine-core.js`, `forge-game.js`: 메인 채굴·제작·기술 보상
- `cloud-config.js`, `cloud-sync.js`, `supabase.sql`: 향후 서버 저장을 위한 유지 코드(현재 미설정)

## 검증 범위

Chromium에서 320px/390px/1440px 화면의 가로 넘침, 마을→시설 선택→업그레이드, 연구/연결 문제→풀이→완료, 이전 JSON 저장 복원, 제작 10종, 생산 보정(예: 제재소 45→54 목재/시간·교역소 골드 50→56/시간), 전초기지 탐험 보상 1→1.12배, 장비 제작 후 실제 효과 계산을 확인했습니다. JS 실행 오류/구문 오류 확인. 실제 GitHub Pages 접속과 iPhone Safari 실기기 테스트는 별도 확인이 필요합니다.
