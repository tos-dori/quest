# Questline v0.8.0 — 단계적 해금과 게임 설정

**GitHub Pages:** https://tos-dori.github.io/quest/ (GitHub Pages 활성화 및 정상 배포가 필요)

## 처음 시작하는 플레이어

신규 저장만 5단계 **직접 플레이 튜토리얼**로 시작합니다.

1. 광석 직접 한 번 때리기 → `hitCount >= 1`
2. 첫 광석 캐기 → `mine.total >= 1`
3. 곡괭이 첫 강화 → `mine.levels.pick >= 1`
4. 실제 일 한 번 기록 → `events.kind === 'real'` 최소 1개
5. 첫 연구 완료 → `researchV4.progress`의 `cleared` 1개 이상

해금은 설명을 넘기는 방식이 아니라 실제 저장 데이터의 결과에 의해 진행됩니다. 완료 후 해금된 기능은 다시 잠기지 않습니다. 새 게임은 처음에 광석과 튜토리얼만, 이후 필요할 때 재화와 메뉴가 나타납니다. 튜토리얼은 건너뛸 수 있습니다.

### 튜토리얼 이후 콘텐츠 해금

| 콘텐츠 | 조건 |
|---|---|
| 퀘스트 | 튜토리얼 4단계 진입 |
| 연구 | 튜토리얼 5단계 진입 |
| 발전·연대기 | 튜토리얼 5단계 완료 |
| 생산 마을·시설 | 튜토리얼 완료 + 모험가 Lv.2 또는 갱도 3층 |
| 공방 | 튜토리얼 완료 + 갱도 3층 |
| 모험 장비 | 튜토리얼 완료 + 모험가 Lv.3 |
| 탐험대 | 튜토리얼 완료 + 모험가 Lv.3 또는 갱도 6층 |
| 꾸미기 | 튜토리얼 완료 + 모험가 Lv.5 |

해금 조건은 플레이 데이터를 덮어쓰지 않습니다. 이전 `firstlight_rpg_v2` 데이터에서 새 `progression` 필드가 없는 계정은 **기존 콘텐츠 전체 해금 유지**로 취급하며, 사용자가 진행하던 시설·연구·채굴·장비·재화·할 일은 보존합니다. 신규 저장만 튜토리얼이 활성화됩니다.

## 게임 설정

헤더 오른쪽 `⚙️`에서 열 수 있습니다.

- **게임:** 애니메이션 줄이기, 큰 글씨, 조작 안내, 진행 중 튜토리얼 건너뛰기
- **저장·계정:** 실제 로컬 저장/클라우드 연결 상태, 전체 JSON 백업, 백업 교체, 여정 기록, 전체 초기화
- **개발자:** 화폐·경험치·갱도·채굴 레벨·시설 레벨 등 숫자 18개 항목 수정, 테스트 잠금 해제
- 치트는 항목 선택 → 현재 값/새 값 미리 보기 → 최종 확인 → 게임 저장 순서로 수행
- **전체 초기화**는 안내 화면 → 마지막 화면에서 `초기화` 직접 입력을 거쳐야 실행
- **백업 교체**는 안내 화면과 기존 import 확인을 순서대로 거침

현재 `cloud-config.js`가 비어 있어 **계정 로그인/로그아웃·기기 간 자동 동기화는 활성화되지 않았습니다**. 연결 전에는 브라우저 `localStorage['firstlight_rpg_v2']`를 사용합니다. 실제 Supabase를 설정하면 계정 메뉴를 열 수 있으나 연동 검증은 별도 작업이 필요합니다. 서비스 계정 삭제, GitHub 계정 삭제 기능은 제공하지 않습니다.

## 안정성·파일 구성

- 기존 `v:2` 데이터 구조/저장 키를 유지. `progression`과 `preferences`만 추가
- `progression.js`: 튜토리얼 단계/해금/이전 플레이어 호환
- `game-settings.js`: 설정·복구·개발자 수치 수정·초기화 확인
- `progression-settings.css`: 게임 설정 UI·튜토리얼 영역과 주요 조작 스타일
- `index.html` 및 `mine-core.js`: 메뉴/재화 노출 제한, 기존 퀘스트 목록 복구 및 광석 터치 안정화
- 나머지 게임·강의 자료·연동 소스 변경 없음

테스트: Chromium 320px/390px/1440px, 새 게임 5단계 튜토리얼, 기존 저장 호환, 설정 3개 탭, 치트 수치 저장, 잘못된 초기화 확인 거부, 정확한 입력 후 초기화, 저장 복원, 가로 넘침·JS 런타임 오류 검사. 이 테스트는 인라인 소스와 **모의 localStorage**를 사용했으며 실제 GitHub Pages, iPhone, Supabase 동기화의 실서비스 검증은 포함하지 않습니다.
