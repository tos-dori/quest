# Questline v0.4.0 — 현실 행동 RPG + 연구 테크트리

현실 퀘스트·성장·탐험을 유지하며 전공 **학습 흐름 자체를 게임 플레이**로 만든 버전입니다.

## 학습

- 4과목, 30개 연구 노드: 운영체제 8 / 마이크로프로세서 7 / 머신러닝 8 / 시스템반도체설계 7
- 과목별 지식 지도와 선행관계·잠금·해금 상태가 표시되는 인터랙티브 테크트리
- 초심자를 위한 개념 동기·용어(영어 원어)·기본 도식·실제 예제·흔한 오류·업로드 강의 PDF 출처 페이지
- 각 노드에 **쉬운 핵심 확인 1개 + 적용·자기설명 1개**, 해설과 모범답안 제공
- 서술형은 자동 채점이 아니라 모범답안과 비교하는 자기평가입니다. 모르는 개념도 재도전할 수 있습니다.
- 골드 소모 힌트, 처음 연구 시 해금 보상, 복습이 필요한 시도에도 소량 보상
- 1·3·7·14·30일 간격의 복습과 완료 노드 랜덤/자유 복습. 반복 보상은 하루 6회까지 제한.
- 기존 28개 객관식의 데이터와 구버전 문제 진입도 보존

**범위:** 사용자가 제공한 강의 PDF에서 학습의 중심이 되는 개념을 선별한 30개 노드입니다. 모든 강의 파일의 모든 주제를 망라하는 것은 아니며 실제 학습 효과는 플레이 후 검증이 필요합니다.

## 배포 및 저장

- 코드: `index.html`, `research-data.js`, `research-game.js`
- 게임 주소: https://tos-dori.github.io/quest/ (Pages 배포 설정이 활성화된 경우)
- 기존 localStorage 키 `firstlight_rpg_v2`, state JSON의 `v:2` 유지
- 신규 연구 상태는 같은 저장 객체의 `researchV4` 아래 추가. 기존 재화·시설·장비·퀘스트·탐험·Todo Mate 사본은 변형하지 않음.
- `cloud-sync.js`, `cloud-config.js`, `supabase.sql`은 기존의 서버 저장 준비 코드. **현재 설정 키가 비어 있어 서버 동기화는 미활성화 상태**입니다.
- 기기 간 사용은 지금은 기록(📔)의 JSON 백업/복원으로 이전합니다.

Todo Mate는 실시간 연동이 아니라 가져온 사본으로만 작동하며, 게임에서 완료해도 Todo Mate 원본은 변경되지 않습니다.
